# Source and build information

The source release contains `GPU/`, a complete snapshot of the renderer's tracked source plus the modified/new VR files, and `OFXR-Bridge/`, the unmodified source corresponding to the bundled v983 bridge. Third-party Git submodules are identified by `source-dependencies.json`; fetch those public repositories at their recorded commits into the indicated paths. Other dependencies are declared by the original CMake files. No game data or proprietary NVIDIA SDK is required to build this GPU configuration: NGX and Streamline are disabled.

The renderer starts from KytyPS5 `u59-windows-20261024-int21` (upstream commit `744705ee1df4b0acb1af382ff5c32ca4a20aa5f7`) plus AstroHybrid's 36 hybrid patches. The local hybrid base commit is `37421f8b600658bab6c283c1aa29f9f6fefd3ec7`. `Source/astrohybrid-vr.patch` contains all subsequent VR changes, including the new physics-capture header. The complete source snapshot avoids depending on the local base commit being available on a public branch.

The tested Windows toolchain was LLVM/clang-cl **21.1.8**, Ninja, CMake, MSVC CRT headers/libraries **14.44.17.14**, Windows SDK **10.0.26100**, and Vulkan SDK **1.4.363.0**. Build from a developer shell with the corresponding `INCLUDE`, `LIB`, and compiler directories configured.

Example configuration, using paths to dependencies available on your machine:

```powershell
cmake -S GPU -B build -G Ninja `
  -DCMAKE_BUILD_TYPE=Release `
  -DCMAKE_C_COMPILER=clang-cl -DCMAKE_CXX_COMPILER=clang-cl `
  -DCMAKE_MSVC_RUNTIME_LIBRARY=MultiThreadedDLL `
  -DKYTY_BUILD_LAUNCHER=OFF -DASTROHYBRID_VR_BUILD=ON `
  -DKYTY_GLSLANG_VALIDATOR="C:/VulkanSDK/1.4.363.0/Bin/glslangValidator.exe" `
  -DFFMPEG_PREBUILT_DIR="<compatible Kyty FFmpeg dependency directory>"
cmake --build build --target kyty_emulator -j 8
```

`ASTROHYBRID_VR_BUILD=ON` changes the target into the shared `kyty_gpu.dll` bridge. Preserve the upstream asset files and compatible runtime system libraries from AstroHybrid 1.2.1. The release uses the OpenXR loader linked into this DLL. Build configuration details are in `GPU/CMakeLists.txt`; obtaining/compiling third-party dependencies follows the original project's instructions. FetchContent dependencies can be overridden with standard `FETCHCONTENT_SOURCE_DIR_<NAME>` CMake variables.

The shipped DLL's SHA-256, payload hashes, base-game hash, and individual byte-patch signatures are in `vr-package.json`. The game patcher preserves the original converted executable and verifies the complete patched output. The installer verifies the source and output hashes for each supported conversion.

OFXR's original build scripts and dependency manifests are included in its source folder. This project ships its v983 binaries unchanged, with process-local manifests and configuration generated by the VR installer. See its original README and third-party notices for bridge build requirements and provider licenses.

The Sky Aztec collision guard and VR HUD installer are included in this release. The headset layout uses five private copies of game files created during installation.

The v0.1.2 renderer uses clang-cl 21, ThinLTO and the bundled stereo gameplay profile. Configure with `-DKYTY_EMULATOR_IPO=ON`, `-DASTROHYBRID_RENDERER_PROFILE=<absolute path to GPU/tools/pgo/astrohybrid-vr-clang21-stereo.profdata>` and `-DKYTY_CP_DIAGNOSTICS=OFF`. Build again with diagnostics ON for `kyty_gpu.diagnostics.dll`.
